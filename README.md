# Laramob — Landscape & Playbook

Site statique d'une seule page (`index.html`), sans dépendance ni build.

Pages : Home, Market, Search, Competitors, Laramob, Playbook, Notes (navigation par `#ancre`).
Données : Google Iran et Instagram collectés le 29.10.2026, audit de laramob.com du 26.10.2026.

## Mise en ligne avec GitHub Pages

1. Pousser ces fichiers à la racine de la branche `main`.
2. Settings → Pages → Source : « Deploy from a branch », branche `main`, dossier `/ (root)`.
3. Le site est servi à `https://<compte>.github.io/<nom-du-repo>/`.

La page contient `<meta name="robots" content="noindex, nofollow">` pour rester hors des moteurs de recherche ; retirer la ligne pour l'indexer.
